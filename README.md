# Dueuno Skills
Develop Dueuno applications with AI


1. Create a new Grails project: `https://start.grails.org/`
2. Copy the `.agents` folder on the project root
3. Load the `dueuno-developer` skill. This depends on the agent you are using. Your IDE may load the `dueuno-developer` skill automatically.

## Write your prompts

### Initialize a new Grails application
```aiignore
Create a Dueuno application.
```

### Create a Domain Class
This will create the corresponding service as well.
```aiignore
Create the domain class Publisher. 
```

### Create a Controller
```aiignore
Create a Controller for books. Make it a favourite feature.
```

### Create a CRUD
```aiignore
Create a CRUD for the domain Book with title, author, and publication date.
```

### Bootstrap a Dueuno application
```aiignore
Create a Dueuno application.
Create a CRUD for the domain Book with title, author, and publication date.
Create a CRUD for the domain Author with name and age.
Make books as a favourite feature.
Create 73 records of mockup data per each domain class.
Credits for the app: Project Manager: Gianluca Sartori, Developers: Francesco Piceghello, Gianluca Sartori
```
